# Lit DevTools panel: visual + token reference (dark theme, 0.21.0)

Captured 2026-10-23 from `feature/promo-video-v3` (plugin 0.21.0, library rebuilt first, `pnpm run build` exit 0).
Same method as `../ref-v2/`: 1920x1080, deviceScaleFactor 1, Playwright Chromium (headless shell 1243, playwright-core 1.63)
with `colorScheme: 'dark'`; the playground page open in one tab and the panel open standalone at `/__lit/` in a second
tab, which follows the page. Playground served on port 5281 (no server was on 5179), examples on 5282-5285 and 4391; all
stopped by PID afterwards. Colour scheme setting = Auto, so the panel rendered dark.

Sources: `packages/webawesome-theme-lit/src/{lit.css,tokens/*.css}` -> generated `src/lib/design-tokens.ts`,
`src/lib/token-text.ts`, `src/panel/*.ts`, `packages/lit-components/src/*.ts`, plus computed styles read from the live DOM
(everything marked "measured" below came from `getComputedStyle` on the rendered element).

Notes on the captures

- Standalone at 1920 wide: tree 1580px | 1px hairline divider at x=1580 | details 340px (x=1581..1920, 12px padding).
- Shots with hover tooltips on purpose: `components-store-global-tip`, `components-request-update-tip`, `components-override-pinned`, `timeline-list-double-render-flag`. `timeline-tracks-range-summary.png` has the lingering axis tooltip (Playwright mouse state) again; crop it.
- `timeline-list-row-detail.png` and `timeline-list-double-render-flag.png` share one session, so the bottom detail pane in the latter still shows the earlier hmr-task row.
- The playground's clocks (`hmr-clock`, `hmr-digital-clock`) update every second, so they top the Updates table and fill the unfiltered List. The cause-chain List shots use the regex filter (`click|hmr-task|task`, `hmr-warnings`) to keep the chain on screen.
- Settings shows two live overrides (`reconnect on [default: off]`, `indicator count shown [default: hidden]`) that came from the dev server's state, not from the capture. Flash is off by default now (v2 shot had it on).

## Fonts (exact)

| Role                                                                             | Stack (`--lit-devtools-font-*`)                                           | Renders as                                                                                                |

| Sans (UI chrome, tabs, buttons, section labels, prose)                           | `ui-sans-serif, system-ui, -apple-system, 'Segoe UI', Roboto, sans-serif` | SF Pro on macOS (no webfont)                                                                              |
| Mono (tree, values, meta, Updates/Timeline rows, inputs, selects, badges, pills) | `'Lilex Variable', ui-monospace, 'SF Mono', Menlo, Consolas, monospace`   | **Lilex Variable**, measured loaded (`document.fonts`: `Lilex Variable w100 700 normal loaded U+0-FF...`) |

Lilex is bundled by the panel: `src/panel/main.ts` imports `@fontsource-variable/lilex/wght.css` (dependency `^5.3.0` in the root `package.json` and `packages/lit-components/package.json`). Files to bundle in the video:

- `node_modules/@fontsource-variable/lilex/files/lilex-latin-wght-normal.woff2` (39.6 KB, U+0000-00FF etc., the one the panel actually loads) and `lilex-latin-wght-italic.woff2` (for the italic _default_ slot name). Other subsets in the same folder: `latin-ext`, `cyrillic`, `cyrillic-ext`, `greek`, `vietnamese`, `symbols2` (normal + italic).
- Real path behind the symlink: `node_modules/.pnpm/@fontsource-variable+lilex@5.3.0/node_modules/@fontsource-variable/lilex/files/`. Licence: `node_modules/@fontsource-variable/lilex/LICENSE` (OFL).
- `@font-face`: family `'Lilex Variable'`, `font-weight: 100 700`, `font-style: normal`, `font-display: swap` (see `wght.css`).
- Built copies (gitignored): `dist/client/assets/lilex-latin-wght-normal-DMDQsmS0.woff2`; also `docs/dist/_astro/`.

The in-page UI (source overlay tooltip, HMR indicator, anatomy labels) loads no font files, so its mono falls back to SF Mono.

Weights: 400 regular, 500 medium (tabs, buttons, badges), 600 semibold (details tag heading, card h3, active segment), 700 bold (brand). Extrabold 800 exists as a token, unused in the panel.

## Radii (Lit corners = square)

`--lit-devtools-radius-xs/sm/md/lg/xl/2xl: 0`; `--lit-devtools-radius-pill: 9999px` ("the one round shape: pills and dots"). Mapped into WA: `--wa-border-radius-s/m/l: 0`, `--wa-border-radius-pill/circle: 9999px`, `--wa-form-control-border-radius: 0`, `--wa-panel-border-radius: 0`.

- Square (0): buttons, inputs, selects, segmented control, tooltips, settings cards, type badges, Updates `skipped`/`re-rendered` badges, `enabled` pill (renders square-ish at 9px), inline code, tree selection.
- Pill 9999px (measured): **Timeline layer chips** and "Show as tracks" chips, **hydration pills**, the tab count badge, Tracks gutter layer dots.
- 50%: tree status dots (6px), list rail dots.
- 2px: hover row action buttons (edit / store / copy / pin / remove), anatomy swatches.
- Layer swatches in chips and list rows are 8px squares (no radius); slot/part swatches in details are 8px squares.
